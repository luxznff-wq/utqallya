# Política de privacidad de Utqallya — borrador

> Borrador técnico pendiente de revisión legal y de completar los datos del
> titular del servicio, domicilio, correo de privacidad y plazos de retención.

Última actualización: 25 de julio de 2026.

## Datos tratados

Utqallya trata los datos necesarios para conectar pasajeros y conductores:
nombre, correo, teléfono, credenciales protegidas, ubicación durante el uso,
origen/destino e historial de viajes. Para conductores también trata DNI,
licencia, SOAT y datos/fotografía del vehículo.

## Finalidades

- Crear y proteger cuentas.
- Solicitar, asignar, seguir y registrar viajes.
- Verificar y administrar conductores.
- Enviar avisos operativos.
- Atender soporte, seguridad e incidencias.
- Cumplir obligaciones legales aplicables.

## Proveedores

El servicio puede usar PostgreSQL/hosting para datos operativos, Cloudinary
para imágenes, Google Maps/Directions para mapas y rutas, y Firebase o Expo
para notificaciones. Antes del lanzamiento deben registrarse los proveedores,
regiones de tratamiento y contratos efectivamente utilizados.

## Ubicación

La ubicación se solicita para seleccionar puntos, encontrar conductores y
seguir un viaje. Debe limitarse al tiempo necesario para prestar el servicio.
El usuario puede retirar permisos desde su dispositivo, aunque ciertas
funciones dejarán de estar disponibles.

## Conservación y seguridad

Se aplican controles de acceso, HTTPS, contraseñas BCrypt y separación de
documentos administrativos. Deben definirse plazos concretos para viajes,
documentos, backups, logs e incidencias antes de publicar esta política.

## Derechos y eliminación

El usuario puede eliminar su cuenta desde Configuración cuando no tenga un
viaje activo. La cuenta se bloquea, los datos identificativos se anonimizan y
los documentos del conductor se eliminan del almacenamiento configurado,
salvo información que deba conservarse por obligación legal.
